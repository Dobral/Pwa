## 📌 О проекте

**MineCoder** — это интерактивный мобильный тренажёр алгоритмического мышления и программирования на JavaScript с помощью библиотеки **Mineflayer**. Приложение разработано специально для подростков 12–17 лет.

### 🔴 Проблема
Большинство традиционных курсов по программированию перегружены сухой теорией, а результат написания кода виден не сразу. На смартфонах неудобно вводить длинные фрагменты кода вручную, из-за чего школьники быстро теряют мотивацию.

### 🟢 Наше решение
* **Микрообучение (3–5 минут):** короткие сессии и четкие практические задания.
* **Без ручной рутины:** удобный интерфейс с блочным выбором, сопоставлением и заполнением пропусков.
* **Знакомый контекст:** решение реальных задач автоматизации и управления ботом в Minecraft.
* **Моментальный фидбек:** визуальное подкрепление и 8-битное звуковое сопровождение ответов.

---

## 🚀 Основные возможности

- 📱 **Progressive Web App (PWA):** Устанавливается прямо на экран смартфона (Android / iOS) и работает offline без сервера.
- 🧱 **4 формата интерактивных заданий:**
  1. *Sequence Builder* — сборка правильной последовательности алгоритма.
  2. *Matching* — сопоставление сетевых терминов и параметров (`host`, `port`, `username`).
  3. *Fill-in-the-blanks* — подстановка вызовов методов из выпадающих списков.
  4. *Bug Hunting* — поиск и исправление ошибок в событиях (`ECONNREFUSED`, ошибки синтаксиса).
- 🏆 **Система геймификации:**
  - Шкала опыта (**XP**) и динамический расчет уровня игрока.
  - 5 уникальных ачивок: *«Новичок»*, *«Сетевик»*, *«Связист»*, *«Оператор»*, *«Мастер»*.
  - Сохранение прогресса в `localStorage`.
- 🔊 **Web Audio API:** Интерактивные 8-битные звуковые эффекты успешных действий и получения достижений.

## 📚 Структура курса (5 уроков)

1. **Урок 1: Введение и софт** — Знакомство с окружением Node.js, пакетами npm и инициализацией проекта.
2. **Урок 2: Запуск и сеть** — Подключение к серверу, параметры `createBot`, IP-адреса и LAN.
3. **Урок 3: Код и ошибки** — Событие `bot.on('spawn')`, обработка ошибок подключения (`ECONNREFUSED`).
4. **Урок 4–5: Команды и чат** — Создание алгоритма автоответчика, реакция на событие `bot.on('chat')` и отправка сообщений.

## 🛠 Технологический стек

* **Frontend:** HTML5, Vanilla JavaScript (ES6+), Pixel Art CSS3.
* **Mobile & Offline:** Service Worker, Web App Manifest (PWA).
* **Audio Engine:** Web Audio API (генерация 8-битного звука без сторонних библиотек).
* **Библиотека контекста:** [Mineflayer](https://github.com/Prismarine/mineflayer) (JavaScript API для ботов Minecraft).

## 💻 Локальный запуск

Приложение не требует сложной сборки или backend-сервера.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/minecoder/app.git
   cd app
   ```

2. **Запустите локальный HTTP-сервер** (например, с помощью Python или VS Code Live Server):
   ```bash
   # Используя Python 3
   python -m http.server 8080
   ```

3. **Откройте в браузере:**
   Перейдите по адресу `http://localhost:8080`.

---

## 📲 Установка на мобильное устройство (PWA)

1. Откройте сайт приложения в браузере мобильного телефона (Chrome / Safari).
2. Нажмите меню **«Поделиться»** (iOS) или **«Настройки»** (Android).
3. Выберите пункт **«Добавить на экран "Домой"»** (Add to Home Screen).
4. Приложение появится на рабочем столе и будет запускаться в полноэкранном режиме без рамок браузера!
