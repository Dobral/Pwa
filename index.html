УРОК 1: СОФТ И ПРОЕКТ

ТЕОРИЯ

Создаем на диске папку, например mineflayer-bot.Для создания бота нам нужны две вещи: Node.js (движок для запуска JavaScript) и библиотека Mineflayer (готовый набор команд для управления ботом).

Затем мы инициализируем проект командой npm init -y, а затем устанавливаем саму библиотеку mineflayer в папку проекта с помощью npm install mineflayer..

ЗАДАНИЕ 1/3: УСТАНОВИ БИБЛИОТЕКУ

Какую команду нужно ввести в терминале VS Code, чтобы установить Mineflayer в проект?

npm mineflayer
ЗАДАНИЕ 2/3: СОБЕРИ КОМАНДУ

Кликни по блокам в правильном порядке (клик по блоку вверху отменяет выбор):

Кликай по блокам внизу
npm
init
-y
ЗАДАНИЕ 3/3: ТЕРМИНЫ

Что делает команда npm install?

а) Создаёт файл package.json
б) Скачивает зависимости и сохраняет их в node_modules
в) Запускает скрипт из package.json

УРОК 2: ЗАПУСК И ПОДКЛЮЧЕНИЕ

ТЕОРИЯ

Чтобы бот зашёл в твой мир, нужно запустить Minecraft, открыть мир для сети (Esc → Открыть для сети) и скопировать пятизначный порт из чата.

Этот порт обязательно нужно прописать в коде в объекте createBot как число, иначе бот не подключится!

Вот так должен выглядить код! const bot = mineflayer.createBot({

host: 'localhost', // адрес сервера

port: 54321, // порт из LAN (замени на свой!)

username: 'MyBot', // ник бота

version: '1.20.1' }); // версия Minecraft (должна совпадать с сервером)

Запустим бота в терминале node index.js

ЗАДАНИЕ 1/3: АЛГОРИТМ LAN

Расположи шаги открытия мира для сети в правильном порядке:

Кликай по шагам
Нажми Esc в игре
Выбери «Открыть для сети»
Скопируй порт из чата
ЗАДАНИЕ 2/3: РАЗБОР КОДА

В этом фрагменте кода есть проблема. Найди её:

const mineflayer = require('mineflayer');
const bot = mineflayer.createBot({
  host: 'localhost',
  port: '12345',
  username: 'BotName'
});
а) Не хватает require('mineflayer')
б) Порт передан строкой '12345', а должен быть числом 12345
в) Ошибка в параметре host — нужен IP-адрес, а не localhost

Имя бота в игре
Адрес сервера (например, localhost)

УРОК 3: КОД И ОШИБКИ

ТЕОРИЯ

Когда бот успешно заходит в мир, срабатывает событие 'spawn'. В этот момент мы вызываем метод bot.chat().

Если в консоли появляется Error: connect ECONNREFUSED — бот не смог подключиться (сервер не запущен или неверный порт).

ЗАДАНИЕ 1/3: ПРИЧИНА ОШИБКИ

Бот упал с ошибкой connect ECONNREFUSED. Что произошло?

а) На компьютере не установлен VS Code
б) Неверно указан порт или мир в Minecraft не открыт для сети
в) У бота слишком длинный ник (username)

УРОК 4: КОМАНДЫ БОТА

ТЕОРИЯ

Бот может ходить, писать в чат и взаимодействовать с миром. Все действия выполняются строго по порядку, как в алгоритме.

Свойства объекта хранят состояние (например, координаты bot.entity.position), а вызовы методов отдают боту прямые команды.

ЗАДАНИЕ 1/3: АЛГОРИТМ БОТА

Расположи команды в правильном порядке, чтобы бот поздоровался, пошёл вперёд и активировал блок:

Кликай по командам
bot.chat('Привет!')
bot.setControlState('forward', true)
bot.activateBlock()
ЗАДАНИЕ 2/3: ГДЕ ОШИБКА?

В коде бот пытается открыть сундук до того, как приблизился к нему. Почему скрипт выдаст ошибку?

bot.activateBlock(chestBlock);
bot.setControlState('forward', true);
а) Бот не может взаимодействовать с блоками вне радиуса досягаемости
б) Команда activateBlock не существует
в) Нужно сначала перезагрузить Minecraft
ЗАДАНИЕ 3/3: СВОЙСТВА И МЕТОДЫ

Выбери подходящие слова, чтобы код логически стал корректным:

// 1. Получаем свойство позиции
const pos = bot.___;

// 2. Метод перемещения бота
bot.___(pos.x + 1, pos.y, pos.z);

// 3. Отправка строки в чат
bot.___('Я на месте!');

УРОК 5: ОТЛАДКА И СОБЫТИЯ

ТЕОРИЯ

События — это реакции на действия в игре. Бот слушает их через метод bot.on('имяСобытия', callback).

  • 'spawn' — сущность бота готова к командам
  • 'message' / 'chat' — пришло сообщение в чат
  • 'health' — изменился голод или очки здоровья
ЗАДАНИЕ 1/3: СОБЫТИЯ БОТА

Сопоставь событие слева с его назначением справа:

'spawn'
'message'
'health'
Изменилось здоровье или голод бота
Бот появился в игровом мире
В чат пришло сообщение от игроков/сервера
ЗАДАНИЕ 2/3: ТИПЫ ДАННЫХ В СОБЫТИЯХ

В событии message параметр jsonMsg приходит как объект. Какая строчка вызовет ошибку?

bot.on('message', (jsonMsg) => {
  // Вызов метода строкового поиска напрямую у объекта:
  if (jsonMsg.includes('привет')) {
    bot.chat('Привет!');
  }
});
а) Ошибки нет, метод includes работает с любыми типами данных
б) jsonMsg — это сложный объект (Chat), нужно применить jsonMsg.toString()
в) Нельзя писать условия if внутри bot.on
ЗАДАНИЕ 3/3: СБОРКА АЛГОРИТМА

Выстрой логический порядок алгоритма для скрипта-автоответчика:

Кликай по шагам
Слушаем событие чата (bot.on)
Проверяем текст сообщения на команду
Отправляем ответ через bot.chat()
Записываем событие в консоль (console.log)
